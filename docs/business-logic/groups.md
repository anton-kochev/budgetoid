# Groups (Legacy Terminology)

The former `Group` concept was a flat transaction category. It was replaced on 2026-07-14 by the
explicit **Category Group → Category** hierarchy and the `/api/category-groups` and
`/api/categories` resources.

There is no live `Group` domain entity, `/api/groups` compatibility endpoint, `GroupId`, or
`GroupName` transaction contract. Historical decision-log links remain pointed here so old entries
retain their original context.

See [Categories and Category Groups](categories.md) for the current rules and
[Transactions](transactions.md) for transaction categorization.
