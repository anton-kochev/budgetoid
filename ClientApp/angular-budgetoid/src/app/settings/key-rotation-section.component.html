Key rotation

Rotating gives your account new keys and re-encrypts every name and note under them. Every passkey and recovery code you have keeps working — the old keys stop opening anything.

This rewrites every record in the account, and nothing can put the old keys back. If this tab closes part-way through, the rotation stops where it is and this section offers to finish it — a rotation picked up again starts over from the first record.
